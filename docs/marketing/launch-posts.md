## 3. LinkedIn — en

```
On 10 September Uzbekistan's Senate approved the new 28-letter Latin alphabet. Four letters change: sh → ş, ch → ç, oʻ → ö, gʻ → ğ.

I have been waiting for this since July, when the Legislative Chamber passed the law and I shipped Alfavit — a converter for the new alphabet — in the same week.

Why it matters technically: the old oʻ and gʻ were a letter plus an apostrophe, and there were more than ten ways to type that apostrophe. Search, URLs and databases broke on them. Typing ö on today's keyboards takes up to six keystrokes. That is the real problem the reform solves, and it is the problem Alfavit exists for during the transition.

What Alfavit does today:
• Web converter (uz/ru/en), runs in the browser, nothing uploaded
• Telegram bot that works inline in any chat
• Chrome extension (right-click → convert)
• Mac app that converts as you type, in any application
• .docx/.txt/.srt files, and a free public API

The engine is open source (MIT) and on npm, so newsrooms, publishers and government teams can run it in their own systems.

If you write Uzbek, or know someone who does: https://alfavit.uz/?utm_source=linkedin&utm_medium=post&utm_campaign=senate-2026-09

Feedback and bug reports very welcome — this is a one-person project built for the transition.
```
