## Etiquette

1. Read the venue's rules first. If self-promotion is banned, DM the admin instead of posting.
2. Ask group admins before posting in groups you joined this week.
3. One post per venue, ever. Later news (extension approved, President signed) goes as a reply in your own thread, not a new post.
4. Say you built it. Never pretend to be a user.
5. Answer every question in the thread for 48 hours. Bugs → GitHub issue, thank the reporter by name in the fix commit.
6. Never post the same text twice in one venue. Never re-add a removed post.
7. If someone criticises the reform itself, stay out of it. Alfavit is neutral infrastructure.
